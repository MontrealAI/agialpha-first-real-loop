# Every Job Teaches

ENGINE-003 requires every evaluated job to leave reusable learning behind. A job may produce an **Accepted Skill Package**, a **Rejected Skill Candidate**, or a **Failure Learning Package**; it may produce more supporting records, but it may not disappear without an evidence-backed lesson.

The reusable learning is grounded in raw evaluator logs, validator results, sandbox records, safety counters, and boundary fields. Accepted skills must carry raw task result identifiers plus ProofBundle and Evidence Docket identifiers before vault publication or import.

This is not a model-weight update claim. A “skill” means a portable, proof-bound capability artifact that can be registered and imported in sandbox constraints.
