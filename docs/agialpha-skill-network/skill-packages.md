# Skill Packages

A Skill Package is a portable proof-bound capability package. It includes source job and agent identifiers, skill type, payload, validated task identifiers, raw task result identifiers, ProofBundle and Evidence Docket identifiers, replay/falsification status, risk tier, activation policy, and boundary fields.

Accepted Skill Packages are measured artifacts. They are not autonomy certificates, not model-weight updates, and not unsupported benchmark-leadership claims.
