# Reviewer Guide

Reviewers should verify: every job produced reusable learning; accepted skills reference raw task results; accepted skills have ProofBundles and Evidence Dockets; at least three target agents imported the skill; imports remain inactive outside sandbox; B6 vs B5 and NetworkSkillPropagationLift are computed from raw logs; replay and falsification pass; token, claim, regulated, redaction, auto-merge, and autonomous-persistence boundaries remain intact.

The reviewer should reject any unsupported exponential, unsupported benchmark-leadership, token-value, regulated decisioning, or safe-autonomy claim.
