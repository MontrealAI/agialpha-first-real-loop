# Replay and Falsification

Replay recomputes held-out metrics and hashes from run artifacts. Falsification audits inject or simulate fake metrics, replay mismatch, unsafe claim, regulated task, missing ProofBundle, missing Evidence Docket, poisoned import, token-value claim, secret-like string, and auto-merge injection.

The claim gate may support local bounded networked skill compounding only when replay and falsification pass.
