# NetworkSkillPropagationLift

`NetworkSkillPropagationLift = D_shared_skill_network(B6) - D_no_shared_skill(B5)`.

`D_network` multiplies held-out success, validator pass, replay pass, evidence completeness, ProofBundle completeness, import success, activation safety, usefulness scores, boundary integrity, and redaction integrity, then divides by cost-risk proxy.

Missing metrics are reported as `not_reported`, `unavailable`, `pending`, or `skipped_with_reason`; missing values are never rendered as fake zeroes.
