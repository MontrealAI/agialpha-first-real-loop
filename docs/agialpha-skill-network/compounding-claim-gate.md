# Compounding Claim Gate

The NetworkCompoundingClaimGate supports only **local bounded networked skill compounding** when all required evidence gates pass: at least five jobs, reusable learning for every job, accepted proof-bound skill, vault publication, at least three imports, B6 vs B5 held-out comparison, replay, falsification, clean hard-safety counters, no token or regulated overclaim, no autonomous persistence, and human review required outside sandbox.

If any gate fails, the status is `not_supported` and the stronger networked skill-compounding claim is not promoted.
